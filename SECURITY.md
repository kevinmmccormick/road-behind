# Security

Treat OMT input as binary data from a trusted local source. The extractor does
not load listed DLLs or execute extracted code. It is not a sandbox and has no
streaming or resource quota protection for huge files.

Report parser problems with a synthetic reproducer and Python version. Do not
upload copyrighted inputs, extracted contents, or private filesystem paths.
For a sensitive report, contact the repository owner privately before opening
a public issue.
